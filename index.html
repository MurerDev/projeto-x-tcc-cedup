METODOLOGIA

Problema

Estudantes do ensino médio têm dificuldade para relacionar o que gostam e sabem fazer com áreas reais e próximos passos de formação e seleção.

Método de cálculo

score(area) = (I*0.35 + H*0.35 + C*0.20) / 0.90 · cada resposta 0–4 × peso 1–3 · até 3 áreas por item

Preferências não somam: filtram e desempatam. Empate persistente: ordem alfabética.

Stack declarada (RNF12)

Protótipo atual: HTML + CSS + JS puro com renderização condicional (mesma lógica do React sem router), LocalStorage como persistência local. Alvo final: React + Express + PostgreSQL (pg) + bcrypt + JWT. Senhas aqui com SHA-256 para demonstração.

Limites do escopo

Não determina profissão, não substitui orientador, sem diagnóstico, sem garantia de emprego, sem IA obrigatória, só dados necessários.
