Sobre o TCC

METODOLOGIA

Problema

Estudantes do ensino médio têm dificuldade de relacionar o que gostam e sabem fazer com áreas reais e próximos passos de formação e seleção.

Método de cálculo

score(area) = (I·0,35 + H·0,35 + C·0,20) / 0,90

Cada resposta vale 0–4 e multiplica o peso da área (1–3). Uma resposta pode pontuar até 3 áreas (RF15). Preferências não somam: filtram e desempatam. Empate final: ordem A–Z.

Stack (RNF12)

Frontend: HTML + CSS + JS com renderização condicional. Backend: Node.js + Express. Banco: PostgreSQL via pg, senhas com bcrypt e sessão com JWT. Tudo roda em localhost.

Privacidade (LGPD)

Dados só do necessário, visíveis só para o próprio estudante, exclusão total da conta apaga resultados, respostas e simulados (RF11). Menores: uso acompanhado pela escola/orientação.

Documentação completa
